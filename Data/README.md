# Data folder

The claims data is patient-level, so **nothing in this folder except this README and the `.gitkeep`
placeholders is committed to git**. Each user supplies the data locally.

| Folder | Contents | Who creates it |
|---|---|---|
| `master/` | `claims_master.parquet`: the enriched claims master (MX + RX claims in long format, one row per code, with code descriptions). **Required.** | You copy it here from the secure data share |
| `warehouse/` | `ciq.duckdb`: the analytics warehouse (facts, dimensions, lines of therapy, `fn_*` stored functions) | Generated by `python -m ciq.build.build_warehouse` |
| `conversations/` | Saved CIQ chat sessions (`<id>.json`), including query results | Generated by the app at runtime |

## Getting the data

1. Request access to the NSCLC claims master from the data owner. The platform only uses
   `claims_master.parquet`; you don't need the raw MX/RX extracts.
2. Copy `claims_master.parquet` into `Data/master/`. Use the secure share only; never email it or put it in git.
3. Run `python scripts/doctor.py` to check it, then `python -m ciq.build.build_warehouse` (about 15 seconds).

`scripts/doctor.py` checks the master file for the columns the build needs.
